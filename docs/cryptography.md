# 暗号化形式・署名・データの扱い

## GitHubの鍵と暗号化形式

| 公開鍵                             | このツールの形式         | 復号に使うもの                             |
| ---------------------------------- | ------------------------ | ------------------------------------------ |
| `https://github.com/username.gpg`  | OpenPGP（GPG互換）       | 対応するOpenPGP秘密鍵。このツールまたはGPG |
| `https://github.com/username.keys` | **age（GPGとは別形式）** | 対応するSSH秘密鍵。このツールまたはage     |

ユーザー名、`@username`、GitHubプロフィールURL、`.gpg` / `.keys` URLを入力できます。Next.js版では、ブラウザが同じサーバーの `/api/github-keys/{username}?type=pgp|ssh` にGETし、サーバーが `https://github.com/{username}.gpg` または `.keys` を直接取得します。`api.github.com` は使わないため、未認証REST APIの60回/時制限に依存せず、ブラウザのCORS制約にも当たりません。GitHub認証やAPIトークンは不要です。GitHubの公開ページ自体に取得制限がかかった場合は、解除時刻の目安と公開鍵ページからの手動取込を案内します。

`.gpg` または `.keys` を指定した場合は、その種類だけを取得します。通常の送信先選択は取得した公開鍵をタブ内で最大1分再利用し、「すべて消去」で破棄します。復号時のGitHub照合・再照合ではこのキャッシュを使わず、サーバーも毎回no-storeで取得します。古い鍵を現在の登録鍵として扱いません。

形式を指定しない場合は、暗号化に使えるOpenPGP鍵を優先し、なければ対応するSSH鍵を使います。「詳細設定」で形式を指定できます。選択した形式に対応する同一アカウントの鍵すべてへ暗号化するので、そのうち1つの秘密鍵で開けます。取得は本人確認の保証ではありません。

- OpenPGPのテキスト出力はASCII armor（`.asc`）、ファイル出力は`.gpg`。
- SSHの出力は標準の`.age`。テキストはage armor、ファイルはバイナリ。
- SSHは **Ed25519 / RSA（2048bit以上）** に対応。パスフレーズ付きOpenSSH、従来の暗号化PEM（RSA）、非暗号化PKCS#8も使えます。暗号化PKCS#8、ECDSA、`sk-`セキュリティキー、SSHエージェント・スマートカード連携は非対応です。
- age本来の`AGE-SECRET-KEY`形式は対象外です。このツールのage機能はSSH鍵向けです。
- OpenPGPの署名専用・期限切れ・失効した鍵は暗号化先から除外します。OpenPGP署名とOpenSSH署名（SSHSIG）に対応します。

## 以前の署名付きデータを開く

現在のアプリに署名を作成する機能はありません。以下は、旧版や外部ツールで作られた署名付き暗号文を読み取る際の仕様です。

復号時は、まず署名・元データ・署名済みGitHubユーザー名の整合性を端末内で確認し、その後GitHubの現在の登録公開鍵を取得して自動照合します。

- **GitHubの公開鍵で検証できました**：署名が正しく、現在そのアカウントに登録された有効な公開鍵で検証できました。
- **現在のGitHub登録鍵では確認できません**：署名自体は正しいものの、現在の登録公開鍵では検証できません。鍵の更新・削除や有効期限も原因になります。
- **GitHub未照合**：オフラインや取得制限等で照合できていません。署名と元データの整合性は確認済みなので保存でき、「再照合」でやり直せます。
- **署名なし**：署名は含まれていません。通常の復号として取り出します。

署名・本文が変更されている場合は、元データを表示する前に処理を止めます。外部で作られた通常のOpenPGP署名付き暗号文にGitHub情報がない場合は、GitHub未照合と表示します。

**旧版で作られたデータを外部ツールで開く場合：**

| 宛先の公開鍵 | 旧版の署名鍵       | 出力と相手の操作                                                                                                                              |
| ------------ | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| OpenPGP      | OpenPGP            | 標準の署名付きOpenPGP（`.asc` / `.gpg`）。GPGの復号で元データを直接取り出せます。署名者の公開鍵が登録されていれば、署名も同時に検証されます。 |
| OpenPGP      | SSH                | `.signed.zip.asc` / `.signed.zip.gpg`。GPGで復号後、ZIPを展開します。                                                                         |
| SSH / age    | OpenPGP または SSH | `.signed.zip.age`。ageで復号後、ZIPを展開します。age自体は送信者署名を検証しません。                                                          |

署名付きZIP v2は、元の名前・拡張子のファイルを `content/` に、署名と公開鍵を `signature/` に入れます。`README.txt` に日本語・英語の手順と、元のファイル名に合わせた実行コマンドがあります。元ファイルを直接検証できる分離署名と、GitHub名・ファイル名・SHA-256ハッシュ・説明書のハッシュを保護するマニフェスト署名の両方が含まれます。OpenPGP署名または標準SSHSIG（名前空間 `dgpg`、SHA-512）を通常の `gpg --verify` / `ssh-keygen -Y verify` で検証できます。同封の公開鍵による整合性確認と、GitHubの現在の公開鍵による署名者の照合は別の確認です。

このアプリはZIPを自動で開き、元データと署名結果を表示します。旧版の4ファイル構成・`dgpg-signed-v1` 形式の暗号文も引き続き復号できます。通常のZIPを暗号化した場合や、元ファイルとして標準署名付きOpenPGPに入れたZIPは、そのままのZIPとして取り出します。

標準署名付きOpenPGPには、非クリティカルな署名済みNotation `identity@dgpg.local` にGitHubユーザー名・元ファイル名・ローカル検証用公開鍵を入れます。本文自体を別の形式に包まないので、通常のGPGで元データを読めます。このメタデータは60 KiB以内です。OpenPGP内部のファイル名はUTF-8で255バイト以下に制限し、超える場合はエラーにします。追加・重複ファイル、シンボリックリンク、圧縮エントリ、改変された説明書等を含む署名付きZIPは受け付けません。

GitHubとの一致は実在人物の身元保証ではありません。そのアカウントの現在の公開鍵と署名の対応を確かめています。秘密鍵やパスフレーズは送信しません。

## データの扱い

- 暗号処理はブラウザのWeb Worker内で行います。本文・ファイル・秘密鍵・パスフレーズを送信しません。
- 操作中の通信は公開鍵取得と署名の照合だけです。Next.jsサーバーへ送信するのはGitHubユーザー名と鍵の種類だけです。署名付きデータの復号時には署名済みユーザー名の登録公開鍵を自動取得します。署名なしの手動鍵入力・暗号処理はオフラインで利用でき、署名付きデータもローカル検証・復号後にGitHub未照合として保存できます。
- 公開鍵取得APIはGETのみで、任意のURLや本文を受け付けません。取得先をgithub.comに固定し、リダイレクトを追わず、15秒・1MiBで制限します。ブラウザからのCookieや認証ヘッダーをGitHubへ転送しません。Web画面のCSPは通信先を同一オリジンに限定します。
- 履歴や鍵はlocalStorageなどに保存しません。外部フォント・解析・CDNはありません。
- バイナリと改行を保持します。プレビューはUTF-8のみ。大きいテキストは先頭100,000文字を表示し、コピー・保存は全文を扱います。
- 暗号化する内容・復号後のデータは最大50 MiB、暗号文入力は72 MiB、鍵は合計1 MiB・100件までです。署名付きZIPには追加の2 MiBまでを許容しますが、元データは50 MiB以内です。UIは簡略表記でMBと表示しています。
- 署名付きデータは署名済みの元ファイル名へ戻します。署名なしのageは元ファイル名を格納しないため、復号時は入力名の`.age`を除いて保存します。暗号文を貼り付けた場合は`decrypted.txt`です。
- 消去は表示・参照を取り除きます。メモリの完全消去を保証するものではありません。
