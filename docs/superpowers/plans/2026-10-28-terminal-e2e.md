# 秘密鍵入力と端末操作の修正

ユーザー指示: 秘密鍵の貼り付けをトグルに隠さず、復号コマンドの失敗をコンテナのE2Eで確認して修正する。既存のpush・PR・mainマージ・本番反映まで進める。

- [x] パスワード付き／なしのGPG・SSH鍵をコンテナ内で作る。個人の鍵・クリップボード・設定はマウントしない。
- [x] 本番ビルドをコンテナで起動し、ブラウザー上で暗号化、保存、生成コマンドのコピーを行う。
- [x] 実X11クリップボードと疑似端末のzshで、コピー＋Enterと複数行貼り付けを実行し、元のバイト列へ戻ることを確認する。保護鍵の対話式パスワード入力も含める。
- [x] ログと同じ失敗を修正前に確認する。1行だけ読む待機と、入力内容の検証・案内を修正し、本文がシェルコマンドや履歴に入らないことを確認する。
- [x] 秘密鍵の貼り付け欄と貼り付け操作を直接表示し、ファイル選択・必要時だけのパスワード表示も維持する。
- [x] ブラウザー回帰・小画面・ユニット・CLI互換性・コンテナE2Eを通し、手順をCIへ追加する。
- [ ] レビュー・push・修正PR・mainマージ・本番反映を確認する。

生成したコマンドはブラウザーから取得した文字列をそのまま端末へ送る。テスト用にオプションを付け替えたり、保護鍵を事前に解除したりしない。クリップボードをモックせず、ブラウザーのCopyとxclipを同じXサーバーへ接続する。Windows実機とmacOSのpbpasteはLinuxコンテナで実行した扱いにしない。
