# 暗号文と秘密鍵の入力元を明示する修正

ユーザー指示: タスクリストを作り、修正PRを作成し、検証後mainへマージする。

## 方針

暗号文の入力元と秘密鍵の使い方は別に選ぶ。コマンドに存在未確認のファイルやSSH秘密鍵のパスを埋め込まない。

- 暗号文を貼り付けた場合、ファイル方式では「暗号文を保存」を先に表示し、保存操作の開始後にコマンドを出す。暗号文を変更したら準備状態を解除する。既にローカルファイルを選んだ場合はその名前を使う。実際の保存先やリネームはブラウザーから確認できないので、実行時のファイル名／パスを編集できるようにする。
- クリップボード方式ではmacOSのpbpaste、WindowsのGet-Clipboard、Linuxのwl-paste／xclipを明示的に使い分ける。コマンドのコピーで暗号文が上書きされるため、コマンドは実行時に「対象をコピーしてEnter」を求めてからクリップボードを読む。暗号文と秘密鍵の両方がクリップボードでも順に別々に取得する。
- GPGでは「GPGに登録済み」「秘密鍵ファイル」「秘密鍵をクリップボードから」を選ぶ。ファイル／クリップボードの秘密鍵は作業用の一時GPGホームへ読み込み、終了・失敗・中断時に片付ける。通常のGPG鍵リングへ勝手に登録しない。
- ageでは秘密鍵ファイルのパス、またはクリップボードを選ぶ。パスは空欄から始める。ファイルを選ぶ場合は名前だけを使い、ブラウザーでファイル内容を読まない。クリップボードの秘密鍵は必要な間だけ権限を絞った一時ファイルへ置き、終了時に削除する。
- ブラウザー方式では暗号文と秘密鍵へ明示的な貼り付け操作を用意する。パスを秘密鍵本文として復号しない。パスが貼られたときはファイル選択へ案内し、自動読み込みや秘密鍵の探索は行わない。
- 秘密鍵や本文を生成コマンドの文字列・シェル履歴へ埋め込まない。ブラウザーのクリップボード読み込みは利用者のボタン操作時だけ。拒否時は手動貼り付けを使えるようにする。

## タスクリスト

- [x] GPG／ageと各OSの標準入力・鍵入力の仕様を確認する。
- [x] コマンド生成を入力元別にし、未選択・空パス・不正パスを検証する。引用・テンポラリ・中止／失敗時の後始末をテストする。
- [x] 貼り付けた暗号文を保存する導線を先に出し、入力変更時に状態を戻す。実ファイル名／パスを編集可能にする。
- [x] 暗号文と秘密鍵の取得元を独立した選択にし、選択した項目だけを展開する。暗黙のGPG登録済み・SSH既定パスをなくす。
- [x] クリップボード方式でコピー順序が壊れない待機を入れ、OS別の実行環境を明確にする。
- [x] Web方式の明示的な貼り付け、権限拒否の復帰、パスと秘密鍵本文の取り違えを直す。
- [x] GPG／ageの保存ファイル・クリップボードと各鍵入力を、使い捨て鍵で実際に復号して確認する。実ユーザーの鍵・クリップボードはテストで使わない。
- [x] 小画面の配置、フォーカス、中止、下書き保持、クリップボード拒否、保存のやり直しをブラウザーで確認する。
- [x] 整形・本番ビルド・ユニット・CLI・ブラウザー回帰を通し、独立レビューで重要な指摘を解消する。
- [ ] 新しい修正PRを作成してpushし、CI成功後mainへマージする。mainのCIとVercel本番反映を確認する。

既存のNext.js＋生成HTML＋Worker構成とGPG／SSH両対応を維持する。新しい実行時依存・秘密鍵の探索・サーバー送信・ブラウザーでの鍵の永続保存は追加しない。

## 配置と確認

通常画面では暗号文・秘密鍵の入力元と必要なパスだけを表示する。コマンド全文は「コマンドを確認」、保存先変更と実行環境はTipsへまとめる。Linuxなどクリップボード環境が未選択の場合はTipsを開く。バイナリ暗号文はファイル方式に限定する。

マージ前レビューで見つかった、パス欄へ秘密鍵本文を貼るとコマンドに埋まる問題を修正した。秘密鍵のヘッダーやage秘密鍵をパスとして受け付けず、内容をエラーへ繰り返さない。Webの相対パスと、画面往復後に遅れて返るクリップボード読み取りも回帰確認に含める。

仕様の確認元: [GnuPG操作コマンド](https://www.gnupg.org/documentation/manuals/gnupg/Operational-GPG-Commands.html)、[ageの使用方法](https://github.com/FiloSottile/age#usage)。統合の最終状態は修正PR・mainのCI・Vercel本番デプロイで確認する。
