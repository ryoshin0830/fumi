# 復号コマンド画面の簡略化

ユーザー指定: コマンド画面は見えるコマンドとCopyだけ。入力元・鍵リング・パス・環境・Tips・折りたたみを削除し、端末で暗号文と秘密鍵を順に貼り付け、復号結果を表示する。

- [x] GPG／age自動判別・貼り付け専用コマンドへ統一する。保護鍵・入力違い・中断・一時領域の削除を維持する。
- [x] 検証できた文章を端末へ表示する。既存のrestoredは上書きしない。バイナリや端末制御文字は固有名で保存し場所を表示する。
- [x] コマンド側の不要な入力・選択肢・Tips・状態・CSSを削除する。Web復号を維持する。
- [x] コンテナで実際のCopyから端末へ送り、GPG・SSH、保護鍵、結果表示、入力違い、空入力、中断、バイナリ、暗号文改変を確認する。
- [x] ユニット・ビルド・CLI互換性・ブラウザー・小画面・レビューを通す。
- [ ] push・修正PR・mainマージ・CI・本番反映を確認する。

macOS／Linuxは共通コマンド、WindowsはOSに応じたPowerShellを表示する。本文を引数・履歴に埋め込まず、クリップボード用コマンドと新しい実行時依存は追加しない。

確認記録: `docs/review/simple-command-verification.md`。統合の最終状態は修正PR、mainのCI、本番デプロイで追跡する。
