# 復号の入力元 — 確認記録

## 修正

- 貼り付けた暗号文は保存操作後にファイル用コマンドを表示する。変更後は再保存が必要。ローカルファイルは実際の名前を使い、別の場所で実行する場合のパス変更はTipsから行う。
- 暗号文と秘密鍵の入力元は独立。GPGは登録済み・ファイル・クリップボード、ageはファイル・クリップボード。SSH鍵の既定パスを入力済みにしない。
- コマンドのコピーでクリップボードが変わるため、実行後に対象をコピーしてEnterを押す。二つの入力元がクリップボードの場合も別々に取得する。
- 鍵ファイル選択は名前だけを使い、コマンド画面で内容を読まない。鍵の本文をパス欄へ貼った場合は拒否し、エラーへ本文を繰り返さない。
- 渡されたGPG秘密鍵は一時鍵リング、クリップボードのSSH鍵は権限を絞った一時ファイルを使い、終了・失敗・通常の中断で片付ける。既存のGPG鍵リングは変更しない。
- Webの貼り付けは明示操作だけ。拒否時は手動貼り付けを案内する。鍵のパスはファイル選択へ案内し、遅れた読み取りは編集・操作切替・消去後に反映しない。

## 実行上の限界

Windows PowerShellは構造・引用・失敗処理・一時領域の削除をテストしたが、Windows実機では実行していない。OSの実クリップボードとネイティブのパスワード入力ダイアログは自動テストの対象外。ダウンロード操作の開始は確認できるが、ブラウザーが最終的に保存した場所・名前は取得できないため、実行前に確認する案内とパス変更を用意する。
