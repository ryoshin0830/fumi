# コマンド画面の簡略化と結果表示

## 変更

コマンド側には、最初から見えるコードとCopyだけを表示する。暗号文や鍵の入力元、パス、鍵リング、実行環境、Tips、コードの折りたたみ、暗号文保存ボタンを削除した。コードはページの入力内容を含まない。Web側の直接貼り付け・ファイル・パスワード・下書き・中止は維持する。

端末では暗号文、秘密鍵の順に貼り付ける。GPG／ageを自動判別し、一時領域で復号する。ネイティブコマンドが成功する前に内容を表示しない。UTF-8の文章は端末へ表示する。無効なUTF-8、危険なC0／C1制御文字を含む内容は固有名のファイルへ保存し、その場所を表示する。既存の`restored`は変更せず、上書き確認も出ない。

## 確認

- 生成処理の新しいテストを旧実装で実行して失敗を確認し、修正後に7件成功。文章の表示、既存ファイルの保護、入力違い、空行、シェル風の文字列、部分的な未検証データを表示しないこと、バイナリ／制御文字、途中EOF、PowerShellの構造を確認する。
- 全ユニット194件、本番ビルド、整形、CLI互換性12ケースが成功。
- 実ブラウザーからコピーしたコードを、コンテナ内の実クリップボードとzshへ送るE2Eが成功。暗号文と秘密鍵も実クリップボードから貼り付ける操作を再現し、保護鍵は実際のpinentry／ageの入力で解除する。
- 13端末ケース: GPG・SSHの保護あり／なしの文章表示4、バイナリ保存2、入力の取り違え2、空入力1、暗号文／鍵の入力中断2、改変された暗号文2。
- 文章が端末へ表示されること、既存ファイルの非上書き、鍵・暗号文が入力中の出力や履歴へ入らないこと、端末設定の復帰、一時領域の削除を確認する。認証エラーでは内容を表示しない。
- Web復号4ケースと、日本語フォントを含む4画面サイズのコマンド／パスワード画面もコンテナで確認する。
- 既存ブラウザー9グループ、段階表示、アニメーション、復号方法が成功。新しいコマンド画面を含む8サイズ88状態ではページと通常フォームの不要なスクロールなし。
- 独立レビューで重要な実装指摘なし。削除した選択肢の説明が残っていたREADMEとデザイン仕様を更新した。

再実行: `npm run test:container`。ローカルのDocker Desktopでは必要に応じて`DOCKER_CONTEXT=desktop-linux`を指定する。確認結果と画面画像は`test-results/container/`へ出力する。

Windows実機での実行は未確認。PowerShellは構造テスト。個人の鍵・設定・クリップボードはテストに使わない。
