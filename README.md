# Fumi

**GitHubの公開鍵で、メッセージやファイルを暗号化。**

[アプリを開く](https://fumi-delta.vercel.app/)

GitHubの公開鍵でテキストやファイルを暗号化し、秘密鍵で復号するツールです。OpenPGP・SSH/ageに対応し、GitHubの現在の登録公開鍵による署名者の照合もできます。

**秘密鍵・パスフレーズ・本文・ファイルをサーバーへ送信しません。** 暗号処理はブラウザのWeb Worker内で実行します。Next.jsサーバーは、GitHubユーザー名・公開アカウントID・鍵の種類を受け取り、公開プロフィール・アイコンと `.gpg` / `.keys` を取得します。

## 起動

Node.js 24を使用します。通常ビルドにはGoやGPGは不要です。

```sh
npm ci
npm run build
npm start
```

<http://127.0.0.1:3000/> を開きます。開発用は `npm run dev`。HTML/CSS/JavaScriptを変更した場合は `npm run build:client` で画面を再生成します。

## 使い方

- **暗号化**：内容と相手のGitHubユーザー名を入力し、「暗号化」。表示された暗号文をコピーするか、ファイルに保存して、メールやSNSで渡します。結果には、実際に使った鍵の持ち主を表示します。
- **復号**：最初に「ブラウザーで復号」「コマンドで復号」を選びます。ブラウザーでは秘密鍵の貼り付け欄を直接表示し、クリップボード・ファイルも同じ場所で選べます。暗号文と秘密鍵がそろうと自動で復号し、必要な場合だけパスワードを求めます。コマンドでは暗号文からGPG／ageを判別し、暗号文と秘密鍵それぞれの入力元を選びます。
- **GitHubに公開鍵がない場合**：GPG・SSH両対応の公開鍵入力が現れます。相手から受け取った鍵を貼り付けるか、ファイルを選びます。GitHubを使わない場合は「公開鍵を使う」も使えます。形式は自動判別し、手動の公開鍵を使うときはGitHubの鍵を使いません。

ユーザー名だけで、暗号化に使えるGPG鍵があればGPG、なければSSH鍵でageを自動選択します。

| 相手の公開鍵               | 暗号化形式 | 相手が使うもの                           |
| -------------------------- | ---------- | ---------------------------------------- |
| `github.com/username.gpg`  | OpenPGP    | このアプリ、またはGPGと対応する秘密鍵    |
| `github.com/username.keys` | age        | このアプリ、またはageと対応するSSH秘密鍵 |

ユーザー名、`@username`、プロフィールURL、`.gpg` / `.keys` URL、公開鍵の直接入力・ファイル選択に対応します。SSHはEd25519とRSAに対応。**ageはGPGとは別形式です。** 新しい署名の作成機能はありません。以前の署名付き暗号文は引き続き復号・検証できます。

宛先を入力すると、公開されている名前・アイコンを表示します。プロフィールの表示は、利用できる暗号鍵や実在人物の身元の確認ではありません。表示に失敗しても暗号化を試せます。暗号化・復号には、文字の変化、手紙の折り畳み、封印や波紋の演出があり、動きを減らす設定にも対応します。

暗号化は1画面で入力して実行します。復号は暗号文と秘密鍵の入力後に自動で試し、必要な場合だけパスワードを求めます。操作の切り替えと結果の「編集」でも入力は保持されます。文字の結果は暗号文・復号文ともすぐに表示し、「コピー」を主な操作にします。ファイルの結果は「保存」を主な操作にします。コピー・保存・実行ボタンは操作領域の下部に固定し、長い暗号文や展開したTips・署名情報は内部でスクロールできます。

コマンドで復号する場合、貼り付けた暗号文は先にファイルへ保存するか、実行時にクリップボードから読みます。秘密鍵は、GPGに登録済みの鍵・鍵ファイルのパス・クリップボードから選びます。SSH鍵の場所を自動で推測しません。ファイル選択で取得するのは名前だけなので、保存先が異なる場合は実際のパスを入力します。コマンドをコピーするとクリップボードが置き換わるため、実行後の案内に従って秘密鍵や暗号文をコピーし直します。GPGの鍵ファイル・クリップボードを使うコマンドは一時鍵リングを作り、終了時に削除します。macOSの`pbpaste`、Windowsの`Get-Clipboard`、Linuxの`wl-paste`／`xclip`に対応します。

端末の入力待ちに鍵や暗号文を直接貼り付けた場合も、ブロック全体を読み取ります。秘密鍵を暗号文として渡した場合は読み直しを求め、本文をシェルのコマンドとして実行しません。入力中は文字を隠し、終了・中断時に端末の表示設定を戻します。

「すべて消去」は両画面の入力・鍵・結果をまとめて消去します。デモ・サンプル生成・多段階の入力ウィザードはありません。

## プライバシーと制限

- 暗号処理・署名の整合性検証はブラウザ内です。サーバーへの操作時リクエストは、公開鍵・公開プロフィール・アイコン取得用のGETだけです。
- 公開鍵はGitHub REST APIを使わず、サーバーが `.gpg` / `.keys` を直接取得します。公開プロフィールはGitHub REST API、アイコンはGitHubの画像配信元から取得します。GitHubの公開ページ自体に制限がある場合は、公開鍵の手動取込を案内します。
- 鍵や履歴を永続保存しません。外部フォント・解析・CDNライブラリは使用しません。Workerも同じホストから配信します。
- GitHubとの一致は、そのアカウントの現在の登録鍵との対応を示します。実在人物の身元を保証するものではありません。
- 元データは50 MiB、暗号文は72 MiB、鍵は合計1 MiBまで。対応鍵・署名・外部ツールでの開き方の詳細は[暗号処理の仕様](docs/cryptography.md)を参照してください。

## 開発・検証

```sh
npm run format:check
npm run build
npm test
npm run test:cli
```

テストにはOpenSSHの `ssh-keygen` とGo 1.27.3以降、CLI互換性検証にはGnuPGも必要です。Go実行ファイルは `GO` 環境変数で指定できます。テストは使い捨て鍵を生成し、個人の鍵リングを使用しません。`test-results/` はGit・Vercelの両方から除外します。

ブラウザ回帰確認にはego-browserを使用します。ローカルサーバーの起動後に：

```sh
npm run fixtures:signatures
npm run test:browser
npm run test:motion
npm run test:disclosure
npm run test:layout
npm run test:methods
# 別の配信先を確認する場合
FUMI_URL=https://your-app.vercel.app npm run test:browser
```

ブラウザスイートは暗号処理に実際の使い捨て鍵を使い、GitHub照合の応答は成功・鍵変更・通信失敗・取得制限の各ケースを再現します。実際のGitHub取得は別途APIで確認します。

Dockerで画面から端末までのE2Eを実行できます。ホストへのGo・GPGのインストールは不要です。

```sh
npm run test:container
# Docker Desktopのコンテキストを明示する場合
DOCKER_CONTEXT=desktop-linux npm run test:container
```

コンテナ内で本番ビルド・Chromium・X11クリップボード・zshを起動し、ブラウザーで暗号化した結果とコピーしたコマンドをそのまま使用します。パスワード付き／なしのGPG・SSH鍵、ファイル・登録済み鍵・クリップボード、複数行貼り付けと入力違い、中断を確認します。鍵・端末・クリップボードはコンテナ内に限定し、ホストへは`test-results/container/`の確認結果だけを保存します。GitHub Actionsでも毎回実行します。

コードの整形は `npm run format`。GitHub Actionsでは整形・本番ビルド・テスト・CLI互換性を確認します。Go/WASMの再ビルドが必要な場合のみ `npm run build:age` を使用し、対応するGoランタイムと依存ライセンスも更新します。

## Vercel

このリポジトリをNext.jsプロジェクトとしてインポートします。Node.js 24、Build Commandは `npm run build`。環境変数やAPIトークンはアプリの動作に不要です。`main` をProduction Branchにすると、以降のpushが本番デプロイになります。

画面は約105 KiB、暗号エンジンは必要時に同一オリジンのハッシュ付き静的Workerとして取得します。生成HTMLはNext.jsのファイルトレースに含めます。初回の暗号処理にはエンジンのダウンロードが必要です。

サーバーなしで使う場合は、`npm run build:client` で生成される `index.html` を開けます。単一HTMLは約9.6 MiBで、暗号エンジンを内包します。**このファイル版の公開鍵・公開プロフィール取得はGitHub REST APIを使用します。** アイコンは頭文字で表示します。 公開鍵の直接入力で暗号処理をオフラインでも利用できます。
